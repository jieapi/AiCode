# 快速上手

从安装到跑通第一条 AI 对话。

## 系统要求

- Android 8.0（API 26）及以上
- arm64-v8a 或 x86_64 设备

## 下载安装

去 [GitHub Releases](https://github.com/jieapi/aicode/releases/latest) 下载，三个包按设备选：

| 包名 | 适用场景 |
| --- | --- |
| `armsolo` | 真机（arm64 设备），体积最小 |
| `x86solo` | 模拟器、Chromebook（x86_64） |
| `universal` | 通用包，同时含两种架构，体积较大 |

::: warning 架构要选对
架构不匹配会导致内置容器无法运行。不确定的话用 `universal`。
:::

推荐直接点击[文档站首页](/)的「下载 APK」，将通过加速镜像直接下载最新正式版的 `universal` 通用包（镜像不可用时自动回退至 GitHub 原链）。

## 1. 首次启动与新手引导

打开 AiCode 进入聊天主页，默认已经新建了一个空会话。首次使用请允许存储权限，否则 AI 无法访问手机文件。

首次启动时，应用会自动开启高亮聚焦新手引导，带你顺次体验「打开侧边栏 → 进入设置配置提供商与拉取模型 → 回到主页选择模型 → 发送第一条消息」的完整闭环；你可以在每个步骤点击高亮控件或卡片上的「下一步」流转，也可随时点击「跳过」。之后如果想重新了解流程，可在「设置 → 重新运行新手引导」再次启动。

## 2. 配置 AI 提供商

AiCode 自己不提供模型，需要先接入一个模型服务。

1. 点主页左上角菜单按钮打开侧边栏，点底部「设置」。
2. 进入「AI 配置 → AI 提供商」，点右上角 + 新建。
3. 填四项：
   - **名称**：别名，比如「官方 OpenAI」。
   - **类型**：`OpenAI` / `Anthropic` / `Gemini` 三选一。第三方中转站一般选 `OpenAI`。
   - **API Key**：你的密钥，形如 `sk-xxx`。
   - **Base URL**：API 根地址。选好类型后会自动填官方地址；用第三方中转时清掉默认值填中转服务的地址，注意**不要带 `/v1` 或后面的路径**。

填完自动保存，不需要手动点保存。

## 3. 添加模型

1. 点刚创建的提供商进入编辑页，底部切到「模型」标签。
2. 两种方式加模型：
   - 点「拉取模型」从服务端同步可用列表，勾选你要的。
   - 点右上角 + 手动输入模型名（比如 `gpt-4o`）。中转站模型名拉不全时用这种。
3. 可选：点模型行编辑元数据（上下文窗口、价格、图片输入与工具调用等能力开关）。

模型添加后自动保存。

## 4. 选择模型

回到聊天主页，点输入框下方工具栏的模型按钮，在弹窗里选刚添加的模型。顶部搜索框可以筛选，模型按提供商分组显示。

## 5. 准备执行环境

「设置 → 运行环境 → 容器与镜像」，两种选择：

- **本地容器**（默认）：用内置的 Alpine Linux，什么都不用配。
- **远程 SSH**：把远程服务器当执行后端，见[远程 SSH 模式](/guide/remote-ssh)。

::: tip 本地容器首次使用要先进终端
容器的首次准备工作（解压系统、装基础工具）只在你进入**终端页面**时才触发。所以第一次使用请先点标题栏的终端进去一次，按提示完成初始化菜单，之后 AI 才能正常执行命令。
:::

## 6. 开始对话

在输入框输入内容点发送。输入框左侧的模式按钮可以在 BUILD、PLAN、AUTO 之间切换，区别见[三种模式](/guide/modes)。

## 实用贴士

- 在主页空会话中选择的模型将被记录为新会话的默认模型，后续新建会话自动沿用。
- 识图、生图与标题总结支持独立指定专属模型，详见[默认模型](/guide/default-models)。
- AI 修改代码前会自动创建快照，支持一键安全回滚，详见[检查点与撤销](/guide/checkpoint)。
- 执行编译等耗时任务前，建议开启[软件权限](/guide/app-permissions)中的后台运行保活，防止系统在切换后台时终止进程。
