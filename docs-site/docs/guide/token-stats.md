# Token 统计与费用

「设置 → Token 统计」记录每一次 AI 调用的消耗，用于查看 token 用量、费用、缓存命中情况与估算输出速率。

页面分为「概览」「请求日志」「分析」三个视图，顶部周期与供应商/模型筛选在各视图间共用。数据从该功能上线后开始记录，已有历史调用不会补造缺失的计时数据。页面实时刷新。

## 周期切换与维度筛选

顶部四个标签：今天 / 近 7 天 / 近 30 天 / 全部。切换后下面所有卡片、图表和列表同步更新。「今天」的趋势图按小时展示，其余按天。

周期下方提供维度筛选条：
- **供应商筛选**：下拉选择「全部供应商」或指定供应商。
- **模型筛选**：下拉选择「全部模型」或指定模型。
- **清除筛选**：激活筛选后出现，点击可一键重置为全部数据。
- 此外，直接点击「供应商统计」或「模型统计」中的任意一行，也可快速将该项设为筛选条件，再次点击即可取消。

## 概览

概览先显示总消耗（输入加输出）、请求次数、费用、缓存命中率、平均输出速率和平均首字节延迟；下方显示近期用量点阵、请求健康时间线和 Token 趋势。点阵按所选周期展示：今天 24 小时、近 7 天 7 日、近 30 天 30 日、全部最多 52 周。近期用量按输入与输出 Token 总量着色；健康时间线按成功率着色，并列出成功、失败和取消数。无请求的时段显示中性色。速率与延迟仅根据具备有效计时数据的成功对话调用计算。

费用是**估算值**，优先使用你在「供应商 → 模型」里填的自定义单价，未填的才按 models.dev 的公开单价计算：缓存读取按缓存价计算，没有缓存价时按输入价的 10% 估；缓存写入按缓存写入价计算，没有时按输入价的 1.25 倍估。总费用按「渠道 + 模型」分别套单价再求和，因此同一个模型从不同供应商调用会各自计价。缓存命中率是缓存读取除以总输入，卡片下方另附本期的缓存读取与写入 token 量。

::: tip 费用仅供参考
这是按公开单价估算的结果，不是账单。中转站改过价格、有折扣，或你使用的模型没有单价数据时，估算会和实际扣费不一致。以供应商后台的账单为准。
:::

## 消耗趋势

折线图展示周期内的输入、输出、缓存命中三条线（蓝色输入、橙色输出、紫色缓存），线下方有半透明填充，方便辨识重叠部分。左轴是 token 数（用 k / M 缩写）。

时间轴按周期完整展开，没有记录的天或小时补 0，因此调用集中在某一天时也能正常看出走势。

**渠道统计**按供应商聚合，展示渠道名称、已配置密钥凭证数量、成功率百分比与横向进度条，右侧突出展示请求次数与 token 消耗，按总消耗倒序排列。

**模型统计**按模型聚合，每行显示模型名、输入输出消耗、调用次数和成功率，按总消耗倒序排列。

分析视图包含渠道与模型排行。点击任意渠道或模型行可快速作为筛选条件联动整页数据。

## 请求日志

每页 10 条，按时间倒序显示模型、供应商、调用类型、状态、输入/输出 Token、速率和总耗时。展开一条记录可查看思考强度、实际发出的思考参数、缓存读写、缓存命中率、首字延迟、费用、重试次数、结束原因与失败信息。

可按调用类型（对话、上下文压缩、标题生成、识图）和状态（成功、失败、已取消）筛选，并和顶部的供应商/模型筛选组合使用。

单次输出速率按「输出 Token ÷（客户端请求耗时 − 首字延迟）」计算，只对成功的对话调用显示；它不包含首字前等待，属于客户端估算，不是服务端纯解码速度。计时缺失、生成窗口不为正或调用没有输出 Token 时显示 `-`。纯工具调用也会统计首字延迟；若没有可计量的输出 Token，则不显示速率。

## 重置

页面右上角的垃圾桶图标可以清空全部调用记录，统计随之归零。会弹确认框，**清空后不可恢复**。
