# 平板与大屏

::: tip 版本说明
本页描述的大屏布局从 1.11.0 起提供。
:::

大屏下 AiCode 会自动换成双栏布局：侧边栏常驻、聊天旁边可以并排开着代码或终端。手机上的界面和操作完全不变。

## 什么时候切换

判断依据是**当前窗口的宽度**，不是屏幕大小：

| 窗口宽度 | 界面形态 |
| --- | --- |
| 窄（多数手机竖屏） | 单栏，侧边栏靠汉堡键滑出，和原来一样 |
| 中等（平板竖握、手机横屏） | 单栏，侧边栏稍宽一些 |
| 宽（平板横屏、折叠屏展开、桌面窗口） | 侧边栏常驻，聊天页可开右栏 |

因为看的是窗口宽度，所以在平板上把 AiCode 拖成半屏或三分之一屏时，它会自动退回单栏，不会挤成一团。

## 常驻侧边栏

宽屏进入聊天页时，会话列表和文件树直接固定在左侧，不用每次滑出来。此时标题栏的汉堡键会消失（侧栏已经在那儿了）。

点文件树里的文件、或者选中另一个会话，侧栏都不会收起，可以连续点着看。

## 并排的工作台

宽屏下聊天页右侧可以并排显示一个面板：

- 点标题栏的**终端**图标 → 右栏开终端，再点一次收起
- 点标题栏的 **Git** 图标 → 右栏开 Git 面板，再点一次收起
- 点文件树里的文件，或点 AI 回复里的文件路径链接 → 右栏打开代码编辑器

右栏当前开的是哪个，标题栏对应图标会高亮显示。

一边看 AI 改代码、一边在右边核对文件内容或跑命令，不用来回切页面。

**调整宽度**：拖动中间的竖线，可以在三七和七三之间任意调整，比例会记住。

**关掉右栏**：点右栏左上角的 ✕，或者按一次返回键。编辑器里有未保存的修改时，仍然会先弹出保存提示。

## 设置页双栏

宽屏打开设置后，左边是设置项列表（一直显示），右边是选中项的内容。切换设置项时只有右半边变化，不再整页跳来跳去。左上角的返回箭头用来离开设置回到聊天。

## 旋转和分屏不再中断

横竖屏切换、拖动分屏大小时，界面会跟着重新排布，但不会重新加载：

- 终端里跑着的命令继续跑，输出不丢
- 编辑器里未保存的修改还在
- 聊天列表停在原来的位置

## 阅读宽度

宽屏下聊天内容不会拉满整个屏幕，而是限制在适合阅读的宽度并居中——一行文字太长时眼睛来回扫描很费劲。右栏打开后左半边变窄，内容会自动跟着收窄。

## 鼠标与触控板

接了鼠标时，把指针移到分栏竖线上会变成拖拽光标，按住左右拖动就能调整两栏宽度。
