# 偏好设置

「设置 → 通用设置 → 偏好设置」放的是不针对某个具体供应商、也不属于某个专用用途的全局偏好开关。改动即时生效，无需保存。

## 模型

**拉取模型后自动移除无效模型**（默认开启）

开启时：在[供应商编辑页](/guide/providers)点「拉取模型」，只要服务端成功返回模型列表，本地列表里那些服务端已不再返回的模型就会被自动移除，并弹出提示告诉你移除了几个。

- 请求失败或服务端返回空列表时不会动本地列表，避免网络异常把你已添加的模型清空。
- 手动添加的模型如果恰好不在服务端返回结果里，也会被一并移除。介意这一点可以关掉开关。
- 关掉后，拉取只负责把新模型列出来供你勾选，不再改动已有列表。

**自动压缩阈值**（默认 85%，可填 1-100 的整数）

上下文用到模型窗口的这个比例时，自动触发上下文压缩（把早期对话摘要成接手摘要）。调大就晚一点压缩、更贴近窗口上限，调小则更早压缩、但摘要更频繁。

**软精简阈值**（默认 60%，可填 1-100 的整数）

上下文用到模型窗口的这个比例时，先静默精简早期对话里的超长工具输出（不调用摘要模型、不产生事件）。目的是让上下文尽量停留在模型质量退化区以下；到自动压缩阈值后才会真正压缩。

## 会话

**启动时会话**（默认「新开会话」）

- **新开会话**：每次打开 App 都从新会话开始。当前工作区如果还留着一个没发过消息的空会话，会直接复用，不会再堆出一个新的。
- **打开最近会话**：直接进入当前工作区里最近更新的那个会话，接着上次聊。该工作区还没有任何会话时会新建一个。置顶会话不会抢过它——即使有置顶会话，也仍进最近更新的那个。

切换工作区时也按同一个偏好处理。

**删除外部工作区聊天记录**（默认关闭）

控制移除「添加本地目录」加进来的外部本地工作区时，聊天记录怎么处理。开启后，移除外部本地工作区会一并删除它的会话与消息；关闭则只解除关联、保留聊天记录，之后重新添加同一目录还能看到历史。

应用内置工作区与远程工作区的删除不受这个开关影响：删掉它们时，目录与聊天记录都会一并删除。

## 输入

**回车键发送消息**（默认关闭）

开启后软键盘的回车键变成发送键，按一下就发出；关闭时回车是换行，由发送按钮发出。多行输入时建议保持关闭。

## 网络

两个超时都用秒作单位，在输入框里填数字即可，**填 0 表示不限制**；保存后对之后的请求立即生效，不用重启。

**首字超时**（默认 300 秒）

发出请求后，等待服务端返回第一个响应块的最长时间。超过就断开重试。慢启动、长思考的模型可以调大。

**数据块间隔超时**（默认不限制）

流式回复过程中，相邻两个响应块之间允许的最长等待。设成具体值后，卡住的连接会更早被断开并重试；网络稳定时保持不限制即可。

**重试次数**（默认 6）

网络请求失败后的指数退避重试次数（不含首次请求，等待从 0.5 秒起步、按 2 倍递增、单次最长 10 秒）。填 0 表示失败直接报错、不重试；同时受多 Key 自动切换影响——被归为 Key 失效的失败会先尝试换 Key 重发。

## 工具

**sendFile 单文件上限**（默认 100MB，可填大于 0 的整数）

AI 用 `sendFile` 把文件发到聊天区时，单个文件允许的最大体积。超过上限的文件不会被发送，AI 会收到失败原因。调大可以发更大的文件，但单个文件会先拷贝到应用私有目录再展示，过大可能占用较多存储。
