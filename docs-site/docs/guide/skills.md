# 技能

技能是为 AI 提供的「专项能力扩展包」——把某类任务的标准流程、最佳实践与专属知识沉淀为规范指南，AI 遇到相关任务时会自动按需加载执行，无需你在每次对话中反复交代背景规则。

入口在「设置 → 技能」。

## 技能从哪里来

一个技能就是一个目录，里面有 `SKILL.md`（或兼容的 `CLAUDE.md`）就会被自动识别。分两级：

- **全局技能**：放在 `~/.aicode/skills/`，跨项目共享，App 升级不丢。
- **项目级技能**：放在 `<工作区>/.aicode/skills/`，只在当前工作区生效，可以随项目提交到 git。远程模式下这里指的是**服务器上**的工作区，读写经由 SSH 完成。

同名技能项目级优先。

你可以直接在 App 里新建技能（见下文），也可以在容器里手工创建技能目录，或者让 AI 帮你从 GitHub 安装。App 会常驻监听技能目录（约 2 秒轮询），手工添加、删除、改名之后列表几秒内自动刷新，不用重进页面。

## 列表页

按「当前项目 / 全局」两个可折叠分组显示，点分组标题展开或收起。

每行是一个技能：图标、名称、描述摘要，名称右侧的彩色勋章表示启用或禁用状态。点行进详情；左滑露出删除按钮，删除会弹确认框——它会直接移除技能目录，**不可恢复**。

右上角「＋」新建技能。

## 详情页

三张卡片：「是否启用」（名称、来源和启停开关）、「摘要」（描述）、「正文」（`SKILL.md` 的完整内容，等宽字体，可以选中复制）。

右上角的铅笔按钮进入编辑页。

## 新建与编辑

编辑页有两组内容：

- **基本信息**：名称、描述、作用域。名称就是 AI 加载技能时用的标识，建议用英文小写加连字符（如 `pdf-report`）；描述写「何时该用它」，AI 靠这句话判断要不要加载；作用域选「当前项目」或「全局」，决定技能目录落在哪一级。
- **指令正文**：技能的完整指令，支持 Markdown。写清这类任务的标准流程、约束与注意事项。

名称和正文都填了才能点右上角「保存」。保存后会写成 `<技能目录>/SKILL.md`，与手写的技能完全等价，之后照样可以用文本编辑器或容器命令改。

几个需要留意的地方：

- **作用域只能在新建时选**。已有技能的作用域是灰的——换作用域等于搬目录，需要你自己在容器里移动。
- **改名只改 `SKILL.md` 里的 `name`，不动目录名**。技能正文里常按 `~/.aicode/skills/<目录>/run.py` 引用同目录脚本，目录跟着改名会把这些引用打断。
- 编辑的是从 GitHub 装来的技能时，如果它用的是 `CLAUDE.md` 而不是 `SKILL.md`，保存会写回原来那个文件，不会多出一份。
- 同一作用域下已有同名技能、名称含 `/` `:` 等不能做目录名的字符、或正文为空时，保存会失败并在页面顶部给出红色提示。

## 启用与禁用

详情页的开关控制这个技能是否参与 AI 会话。禁用后它不再出现在系统提示的可用技能清单里，AI 也无法加载，可以减少上下文占用——技能装多了之后这个开关很有用。

禁用名单写在 `skills.json` 里（全局是 `~/.aicode/skills.json`，项目级是 `<工作区>/.aicode/skills.json`；远程模式下项目级名单存在手机本地，按工作区隔离），格式是：

```json
{ "disabled": ["技能名"] }
```

两级取并集，任一作用域禁用即生效。也可以直接手工编辑这个文件，几秒内自动生效。
