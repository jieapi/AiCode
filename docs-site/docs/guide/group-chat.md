# 群聊协作

::: tip 版本说明
群聊协作属于尚未发布的功能（**1.11.0 起**），当前正式版里找不到它。
:::

群聊让多个子代理（成员）在同一个房间里协作：你发一条消息，被 @ 的成员轮流回应，可以互相转交任务、汇报结果，聊到没人接话就安静下来。每个成员都来自「子代理」里的自定义 agent 定义，有自己的头像、名字和专属提示词。

## 创建群聊房间

1. 打开侧边栏，切到「**群聊**」标签页。
2. 点「**新建群聊**」，填房间名，勾选成员（2-6 个），创建。
3. 房间里就可以直接聊天了。

## 房间聊天

- 在输入框发消息会触发一轮群聊：被 **@成员名** 点名的成员回应；没点名时大家都会看一眼，谁有相关的话谁说。
- **@all** 让所有成员都回应。
- 一轮最多跑 3 个来回、10 条消息，全员 pass 后房间安静下来。
- 成员发言会以成员头像+名字的气泡显示在房间里。

## 暂停与恢复成员

- 输入 **@all stop**（或 `@成员 stop`）暂停全员（或单个成员），成员不再发言。
- 输入 **@all resume**（或 `@成员 resume`）恢复。
- 房间顶部成员条上也能看到被暂停的成员，点「全部恢复」一键恢复。

## 定时任务（Routines）

给某个成员安排周期任务，到点自动以「用户消息」的形式在房间里触发一轮，让该成员执行并汇报结果。点房间右上角的**时钟按钮**打开定时任务面板：

- **新建**：选择执行成员、填写调度表达式和指令。
- **运行一次**：立即触发，不等扫描周期。
- **开关**：停用后不再触发；**删除**移除任务。

### 调度表达式

| 格式 | 含义 | 示例 |
| --- | --- | --- |
| `every Nm` | 每 N 分钟 | `every 30m` |
| `every Nh` | 每 N 小时 | `every 2h` |
| `every Nd` | 每 N 天 | `every 1d` |
| `hourly` | 每小时 | `hourly` |
| `daily HH:MM` | 每天固定时刻 | `daily 09:30` |

注意：定时任务由系统后台周期扫描触发，**最短约 15 分钟一次**（更密的表达式也会按 15 分钟执行）。App 进程被系统回收后，任务触发会延迟到下一次进程运行；此时消息会落在房间里，下次你进房间发消息，成员会补上处理。

## 成员私信（Bot Chat）

群聊成员之间可以互相私信（不占用房间消息）。当某个成员需要单独对接另一个成员时，会通过私信沟通，结果再汇报到房间。你可以在房间的侧边栏展开里看到每个成员的「**Bot Chat**」会话，点开查看双方的私信内容。

## 常见问题

- **房间没人回应**：检查是否 `@all stop` 把成员暂停了（成员条上会显示「已暂停」）；全员都 pass 也说明没什么可说的，属正常。
- **定时任务没触发**：确认成员还在房间里、任务开关是开着的、调度表达式合法；App 被杀后任务会顺延到下一次进程运行。
