# 插件

::: warning 预览功能
插件功能正在分阶段开发。目前只支持从本地 `.zip` 文件导入，插件只能为 AI 增加**技能**和**子代理**；它不会运行任何第三方代码，也还没有在线插件市场。
:::

插件是一个 `.zip` 包，可以一次性给 AI 带来若干技能和子代理，并由你统一启停、授权和卸载。想自己做一个插件，见[开发插件](/advanced/plugin-development)。

入口在「设置 → 插件」。

## 导入插件

1. 点右上角「＋」，在文件选择器里选中插件的 `.zip` 文件。
2. 读取完成后弹出「安装插件」，依次显示：名称、版本、发布者、简介，以及**将提供的内容**（每个技能、子代理的名字和说明）和**需要的权限**。
3. 在「需要的权限」里决定授权：标着「必要」的固定开启，关掉就装不了；标着「可选」的**默认关闭**，打开后对应的内容才会生效。
4. 点「安装」。装好后插件出现在列表里并立即生效（AI 的技能清单需要新开会话才会刷新，见下文）。

如果文件有问题，会弹窗逐条列出原因，什么都不会被安装；常见原因见本页末尾的〈出错怎么办〉。

## 安装前先看这几点

- **AiCode 无法核验本地文件的来源。** 请只安装你信任的人提供的插件，弹窗里显示的「源码仓库」是插件自己写的，AiCode 不会去核实。
- **技能和子代理的内容会直接影响 AI 的行为。** 它们是一段段指令，名称和描述还会写进 AI 的系统提示词。装一个你没读过的插件，就等于让 AI 照着别人写的指令办事。
- **插件本身不执行代码。** 安装和使用过程中，AiCode 只是读取包里的文本文件，不会运行包里的任何程序或脚本。
- 子代理的行为仍受当前模式约束（Plan 模式下只读），插件无法提升权限，也不能指定使用你的哪个供应商或模型——插件子代理一律沿用主会话的模型。

## 列表与详情

列表每行是一个插件：名称、版本、发布者，右侧的开关用来启用或停用。副标题里可能出现这些状态：

| 状态 | 含义 |
| --- | --- |
| 已停用 | 你关掉了开关，它提供的内容全部不生效 |
| 待授权 | 必要权限被你关掉了，插件暂时不生效 |
| 已损坏 | 插件文件丢失或被改动过，无法启用；请卸载后重新导入 |
| 不可用 | 这个插件与当前版本的 AiCode 不兼容 |

点一行进入详情页，从上到下是：

- **启用插件**：总开关；
- **简介** 与 **信息**：版本、发布者、许可证、插件自述的源码仓库、来源（目前都是「本地导入」）；
- **提供的内容**：这个插件带来的技能和子代理。对应权限没开或插件没生效时显示为灰色；
- **权限**：逐项开关，旁边写着插件申请它的理由。随时可以关掉，关掉后对应内容立刻不再可用；
- **卸载插件**：删除插件文件和它的授权记录，它提供的技能和子代理一并消失，无法恢复。

## 在对话里怎么用

- **技能**：和普通技能一样，AI 会按需加载，你也可以在输入框用 `/` 菜单触发。插件技能的名字带着插件 ID 作前缀，形如 `community.demo-kit:project-notes`，所以不会和你自己建的技能重名。
- **子代理**：同样带前缀，AI 派发时用这个完整名字；也会出现在 AI 可派发的子代理清单里。

`/` 菜单每次打开都会重新读取，新装、停用或卸载插件后马上可见。不过和普通技能一样，**AI 的可用技能清单在会话开始时生成，需要新开会话才会看到更新**；子代理清单则在下一轮对话就会刷新。

「设置 → 技能」和「设置 → 子代理」两个页面只列出你自己创建的内容，插件提供的内容请到「设置 → 插件」里查看。

## 更新与替换

再次导入一个**同 ID** 的插件包，就是替换安装：弹窗里会提示「已安装 x.y.z 版」，继续会整体替换旧版本。**权限需要重新确认，不会继承上次的授权**；如果导入的就是已安装的同一个文件（内容逐字节一致），弹窗会告诉你；同一个插件被重新打包过，即使内容没变，也会被当作不同的包。

## 和其他功能的关系

- **远程 SSH 模式**：插件和它的授权保存在手机上，切换到 SSH 模式不受影响，也不会被上传到服务器。
- **备份与还原**：插件暂时**不在**备份范围内，换手机或清除数据后需要重新导入。
- **工具授权**：插件的授权只决定「它的内容生不生效」，不会改变你在「工具授权」里对 AI 工具的任何设置。

## 出错怎么办

| 提示 | 怎么办 |
| --- | --- |
| 这个文件不是有效的 ZIP 压缩包 | 确认选的是 `.zip`，并且没有下载一半；有些文件管理器会把 `.zip` 显示成其他类型，换一个文件管理器再试 |
| 压缩包根目录里没有 plugin.json | 打包时多套了一层目录，需要让 `plugin.json` 直接位于压缩包根部 |
| 此版本暂不支持的内容类型 / 权限 / 字段 | 这个插件用了当前版本还没实现的功能（如工具、MCP、自带页面）。等 AiCode 升级，或联系插件作者提供仅含技能和子代理的版本 |
| 插件要求的插件接口版本不兼容 | 插件针对更新（或更旧）的 AiCode 编写，需要升级 AiCode 或更换插件版本 |
| 压缩包过大 / 文件过多 / 路径不安全 / 重复文件 | 包不符合安全限制，请联系插件作者；AiCode 不会放宽这些限制 |
| 其余「plugin.json 缺少/无效字段」「内容无效」「文件不存在」 | 都是插件包本身的问题，提示里会写明具体字段或文件，转给插件作者修复 |
