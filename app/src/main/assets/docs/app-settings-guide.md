## 1. 顶部标题栏 (ChatHeader)
App 最顶部是聊天页标题栏，包含：
*   **菜单按钮**（左上）：打开侧边抽屉，管理会话列表。
*   **会话标题 + 模型名**：当前会话名称（上）与当前启用的模型名称（下）上下排列。
*   **新建会话**：开始一个新的聊天。
*   **Git 入口**：跳转到 Git 版本管理页。
*   **终端入口**：跳转到终端页。
*   **SSH 连接状态（仅远程模式）**：标题栏下方一行，左侧显示 SSH 连接状态指示（圆点 + 文字：已连接 / 连接中… / 连接失败 / 未连接），右侧显示当前会话的 token 累计统计（↑输入 ↓输出）。仅远程 SSH 模式下显示，本地模式不显示。
*   **远程连接占位提示**：远程模式下若连接未就绪，消息区显示占位提示（如「正在连接远程服务器…」「远程服务器连接失败」），避免空白。

## 1.1 侧边栏 (ChatDrawer)
点击标题栏左上角菜单按钮（或从屏幕左缘右滑）打开侧边抽屉：
*   **历史记录**：会话列表按最后回复时间从新到旧排列，并按时间分组显示标签（今天 / 昨天 / 7天内 / 30天内 / 更早按月，如「2026年5月」）；置顶的会话单独显示在列表最前部的「置顶」分组，卡片背景为浅蓝色。短按选中并切换到该会话；**长按弹出操作菜单**（置顶/取消置顶 / 重命名 / 导出 / 删除）：
    *   **置顶 / 取消置顶**：置顶后该会话固定排在列表最前的「置顶」分组并显示浅蓝背景，再次长按选择「取消置顶」即可恢复按时间排列。
    *   **重命名**：弹出对话框输入新名称，确认后更新会话标题，不影响列表顺序。
    *   **删除**：弹出确认框，确认后删除该会话及其所有消息。
*   **设置**：底部入口，点击跳转到设置页。

## 2. 聊天输入框下方工具栏
滚动消息列表时，输入框区域（含工具栏、附件预览、排队面板）会淡出到 40% 以降低阅读干扰，停止滚动后恢复；底部渐变蒙版始终保留，滚动内容穿过输入框时仍被遮罩。

输入框支持**多行输入**：软键盘回车键用于换行，发送通过右下角发送按钮完成；AI 工作时输入框仍可输入，内容会进入待发送队列。

输入框下方一行是操作工具栏，从左到右依次为：
*   **模式按钮**：点击在 BUILD → PLAN → AUTO 间循环切换（详见下节）。
*   **模型按钮**：显示当前启用的 AI 模型，点击弹出模型选择弹窗：顶部搜索框可模糊筛选，模型按提供商分组展示，每行标注能力标签（`Image` / `Tools` / `↑`输入 / `↓`输出），当前模型带选中标记，点击即可切换。
*   **工作区按钮**：显示当前工作区名称，点击弹出工作区管理面板（底部弹窗）：
    *   列出所有已创建的工作区，点击切换。若当前有正在运行的 AI 会话或终端标签，会弹出确认框提示切换会停止它们。
    *   可新建工作区（输入名称创建）。
    *   可删除已有工作区。
    *   工作区是 AI 操作的代码项目根目录，每个工作区对应手机上的一个独立文件夹，AI 的代码读写和命令执行都被沙盒隔离在当前工作区内。
*   **文件按钮**（文件图标）：上传文件作为附件，AI 可读取其内容。非忙碌时可用。
*   **图片按钮**（图片图标）：上传图片作为附件，AI 可识别图片内容。点击直接打开系统相册（Photo Picker）多选图片；老设备无相册能力时回退系统文件选择器。需当前模型支持图片输入，非忙碌时可用。
*   **发送按钮**：发送当前输入；AI 工作时输入框为空显示停止按钮，有内容时显示橙色发送按钮（消息将排队发送）。
*   上传的附件会以预览卡形式显示在输入框上方，可移除后再发送。
*   **斜杠命令**：在输入框输入 `/` 会弹出命令菜单，支持以下命令：
    *   `/status`：查看当前会话状态（token 用量、模型、模式等），结果以 AI 气泡输出。
    *   `/compress`：手动触发当前会话的上下文压缩。
    *   命令在 AI 忙碌时会进入待发送队列，空闲时自动执行；命令文本会作为用户消息显示在对话中，并进入对话上下文。

### 2.1 消息队列
AI 工作时输入框仍然可用，输入内容后点击发送按钮（此时为橙色）不会打断当前任务，而是将消息加入**待发送队列**：
*   队列面板显示在输入框上方（样式与斜杠命令菜单一致），列出排队消息的序号与摘要，数量显示在面板标题。
*   当前一轮 AI 任务结束后，队列中的下一条会自动发送执行；排队多条时按顺序依次执行。
*   点「停止」按钮会跳过当前轮任务，立即执行队列中的下一条。
*   排队内容过多时，面板内部可滚动；每条消息右侧的 × 按钮可将其从队列移除。
*   斜杠命令同样排队：AI 忙时发送 `/status`、`/compress` 会先进入队列，轮到执行时命令会作为用户消息显示并进入对话上下文。
*   队列仅保存在内存中：切换工作区或进程被杀时会清空。

### 2.2 AI 回复打字机效果
AI 生成回复时，回复气泡以**打字机效果**逐字显示，打字速度跟随模型吐字速度自动调节：模型吐得快显示快、吐得慢或停顿时以较慢速度匀速补完。思考过程气泡与工具执行输出保持实时显示，不受打字机影响；回复生成结束后内容会立即补全为完整文本。

### 2.3 工具调用入场动画
AI 执行工具调用时，工具卡片以淡入 + 展开动画逐个平滑出现，不会突然整批蹦出；落库后的历史会话翻看时不重播动画。

工具卡片点击标题栏可折叠 / 展开查看「指令」与「结果」；**执行中默认收起只留一行状态**，工具（如 bash）实时输出刷屏时不会遮挡聊天区，点击标题栏即可展开查看工具参数与最新输出，输出进行中指示（跳动圆点）显示在结果区下方。

## 3. 核心模式切换 (Plan / Build / Auto)
工具栏左侧的模式按钮点击在三种模式间循环切换：**BUILD → PLAN → AUTO → BUILD**。
*   **BUILD (构建模式)**：全功能模式，解锁写权限。AI 可以帮用户写文件、修改代码以及运行构建命令。
*   **PLAN (计划模式)**：进入此模式后，系统物理级锁死 AI 的写操作权限。AI 只能进行代码阅读、检索和方案构思，绝不会修改任何文件。
*   **AUTO (自动模式)**：权限全放行模式。所有工具调用（写文件、执行命令、终端操作等）自动批准，不弹权限确认窗。仅灾难性删除（`rm` 根目录/系统目录等）仍被拦截。该模式权限极大，适合用户已明确知晓风险、希望 AI 全自动完成批量任务的场景。
*   *提示：除了用户手动点按钮切换，AI 自己在规划清晰后，也可以通过调用 `switchMode` 工具向用户发送切换模式的请求，用户在界面上一键批准即可。注意：AUTO 模式只能由用户在界面上手动进入，AI 无法通过工具切换到 AUTO；但处于 AUTO 模式时，AI 可通过 `switchMode` 切换到 PLAN 模式退出自动模式（这是 AI 退出 AUTO 的唯一路径）。*

## 4. 设置首页菜单项
“设置”首页按五个分组列出二级入口：
*   **AI 配置**：AI 提供商 / 默认模型 / MCP 服务器 / 技能。
*   **运行环境**：容器镜像 / 连接与同步。
*   **工具与权限**：工具授权 / 软件权限 / 日志。
*   **外观与语言**：外观主题 / 背景图 / 语言。
*   **系统**：Token 统计 / 备份与还原 / 使用手册 / 关于。

「使用手册」入口点击后调用系统浏览器打开 GitHub Wiki（`https://github.com/jieapi/aicode/wiki`），查看面向用户的使用文档与常见问题。

各入口的详细说明与对应文档见上方「文档索引」；部分菜单行会显示当前值（如提供商数量、容器 profile 名、日志等级名）。

### 4.1 提供商级 LLM 缓存开关

「AI 提供商」编辑页的「选项」分组内提供两个**提供商级**缓存优化开关，按提供商类型显示，用于降低重复请求的输入成本：

*   **Anthropic 缓存断点**（Anthropic 类型显示，默认开启）：为 system / 工具定义 / 最新用户消息前缀添加显式 `cache_control` 断点，启用 Anthropic 官方 prompt caching，跨轮请求命中缓存后输入价格降至 0.1x。若使用的第三方 Anthropic 兼容网关对未知字段校验严格而报 400，请关闭此开关。
*   **OpenAI 兼容缓存键**（OpenAI 类型显示，默认关闭）：为 Chat Completion 请求附带 `prompt_cache_key`（会话级 shard 路由键），让同一会话的请求路由到同一缓存分片，提升 DeepInfra / Cerebras / OpenRouter 等第三方兼容服务的缓存命中率。OpenAI 官方 Chat Completion 不接受该字段（会返回 400），因此默认关闭——使用官方 API 时请勿开启。

> 说明：OpenAI 官方 Responses API 原生支持缓存键，会无条件附带 `prompt_cache_key`，不受该开关控制。
