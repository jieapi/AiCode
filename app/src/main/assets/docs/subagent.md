# 子代理 (Subagent)

子代理（subagent）是一个特殊的会话：由主会话的 AI 通过 `task` 工具创建，相当于**替用户向一个新会话发消息**，子代理会像普通会话一样自动开始回复。子代理拥有独立上下文与完整工具能力，可以和主代理并行干活；用户也能随时点进去查看进度、自己发消息或暂停。

## 如何使用

在对话中让 AI 使用 `task` 工具，例如：

- 「派个子代理去审查 `app/build.gradle.kts`，把问题列出来」
- 「创建两个子代理，一个研究数据库迁移方案，一个调研 UI 组件库选型」
- 「让子代理独立实现 `sendFile` 功能并跑通测试」

AI 会先征求你的同意（权限弹窗），创建后立即返回子会话 id，**不阻塞主对话**；子代理在后台自动开始工作。

## 与普通会话的关系

| 能力 | 普通会话 | 子代理会话 |
|---|---|---|
| 用户查看/发消息/暂停 | ✅ | ✅（和普通会话完全一样的界面） |
| AI 替用户发消息 | ❌（只有用户能发） | ✅（创建者 AI 可替用户发） |
| 独立上下文与完整工具 | ✅ | ✅ |
| 主会话并行运行 | — | ✅ 可同时派多个，各干各的 |

## 侧边栏里的子代理

侧边栏顶部有两个标签页：**会话** 与 **文件**。子代理不单占一个标签页，而是就地挂在它所属的会话下：

- 在「会话」页，凡是派生过子代理的会话，行尾会显示子代理**数量**与一个展开箭头。
- 点箭头展开，该会话的子代理会缩进列在它下方（运行中的显示绿色状态点）；再点一下收起。
- 每个展开的子代理下方会显示一张**状态卡片**：实时展示正在执行的工具名与滚动输出，运行中的显示「停止」按钮，点右侧箭头可跳进该子会话查看详情。
- 点子代理项即切换到该会话，界面和普通会话一模一样，没有特殊按钮；长按同样可置顶/重命名/导出/删除。
- 回到主会话只需在「会话」页点选父会话。

没有子代理的会话行不会出现展开箭头。

## 并行任务分发

一次可批量派出多个子代理并行执行，并用等待操作汇总结果：

- `task(action="batch", tasks=[{"description":"审查模块A","prompt":"请审查 ..."}, {"description":"修复模块B","prompt":"请修复 ..."}])`：**一次性创建多个子代理并行执行**，返回创建的 ids 列表。批量创建会先校验可用槽位（最多 5 个同时运行）。
- `task(action="wait", ids=["id1","id2"], timeout=300)`：**挂起等待**指定子代理全部完成（COMPLETED/FAILED/STOPPED 任一终态），返回每个子代理的最终状态与最后输出。超时（默认 300 秒，可调）返回已完成的子代理结果并提示未完成的仍在运行。
- `task(action="waitAll", timeout=300)`：等待当前会话**全部**子代理完成并汇总结果（等价于 wait 不带 ids）。
- `task(action="list")`：列出当前会话全部子代理及状态，可与 wait 组合用于分批处理。

> 使用建议：批量创建后用 wait 等待并一次性取回所有结果，主代理无需逐个子代理轮询；wait 会阻塞当前轮次直到完成或超时，适合需要汇总后才继续的场景。

## 子代理的异步回调

子代理完成后，主会话会收到一条后台通知（与终端异步回调同机制），主代理据此得知子代理已结束。`task` 工具支持多种操作：

- `task(action="read", id=...)`：读取指定子代理的最后输出
- `task(action="stop", id=...)`：主动停止指定子代理（已产出的内容保留）
- `task(action="del", id=...)`：删除指定子代理会话及其全部消息（运行中会先停止）
- `task(action="list")`：列出当前会话的全部子代理及状态

## 子代理的模型与模式提醒

子代理默认继承主会话的模型。如果你希望子代理用不同模型，可在**设置 → 默认模型 → 子代理模型**里配置**预设列表**：

- 每一行一个预设（默认命名「子代理1」「子代理2」…），行内可修改名称、点「❗」配置模式提醒、点下拉选模型、点 ➕ 新增下一行、✕ 删除本行。
- AI 批量创建子代理且**未显式指定模型**时，按行顺序自动分配：第 1 个子代理用「子代理1」、第 2 个用「子代理2」…；超出预设个数或列表为空，回退主会话模型。
- 也可以在 `task` 的每个任务里显式传 `preset`（按名称匹配，如 `"preset":"子代理1"`）或分别传 `providerId`/`model` 指定不同模型。
- **模式提醒**：每个预设可配置提醒文本（如「自动模式 AUTO」）。内置 AUTO/PLAN 两个预设 key——勾选后子代理会话会**真正进入对应模式**（AUTO 全放行不弹窗 / PLAN 只读），模式规则全文由系统按会话模式自动注入；也支持自定义文本，创建时注入子代理第一条消息末尾。

## 限制

- **最多同时运行 5 个子代理**：创建超限时 `task` 会报错，需要等某个子代理完成或先用 `task(action="stop")` 停止后再创建。
- 子代理不能嵌套创建子代理（其工具集中不含 `task`）。
- 子代理与主会话共用同一权限体系，需要授权的操作仍会弹出确认。
- 删除父会话时，其下的所有子代理会话会一并删除。
