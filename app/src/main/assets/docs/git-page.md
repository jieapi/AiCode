# Git 版本管理

在项目工作区打开 Git 页面，可视化管理代码版本。页面底部是悬浮胶囊 tab 栏（伪液态玻璃效果），切换三个标签页：**状态**、**分支**、**提交**。非 Git 仓库进入时会提示初始化（`git init`）。右上角钥匙图标可进入独立的「凭据与署名」页，底部悬浮胶囊 tab 切换「署名」与「凭据」两个标签页。

## 多目录识别

Git 页自动识别当前工作区根目录及其**一层直接子目录**里的 Git 仓库：

*   顶栏标题下方显示当前仓库名，点击可弹出仓库选择列表，在多个仓库间切换。
*   仓库选择列表列出工作区根与各子目录，Git 仓库带「Git」标记，当前仓库带勾选。
*   若工作区根不是 Git 仓库但子目录是，会自动选中子目录仓库，展示其状态/分支/提交。
*   工作区根与子目录都找不到 Git 仓库时，显示「非 Git 仓库」提示，可「初始化 Git 仓库」（在当前工作区根执行 `git init`），也可点「选择已有仓库」手动指定任意子目录作为仓库。

## 1. 状态 (Tab 1)

查看当前仓库的工作区状态，分暂存区与工作区两部分：

*   **当前分支与跟踪信息**：顶部卡片显示当前分支名、领先/落后远程的提交数（↑/↓），以及已暂存/已修改/未跟踪的文件计数。
*   **提交**：全宽主按钮。需先暂存改动并配置署名才可点击，点击后弹出输入框填写提交信息（`git commit -m`）。
*   **批量操作**：
    *   「暂存全部」（`git add -A`）。
    *   已暂存分组标题右侧的「全部取消暂存」（`git reset`）。
    *   「拉取」（`git pull`）与「推送」（`git push`）：需已配置远程仓库；当前分支无上游时推送自动 `git push --set-upstream` 首推建关联。
*   **文件改动列表**：按「已暂存 / 已修改 / 未跟踪」分组建卡片展示：
    *   **已暂存**：点击行打开 `HEAD → 暂存区` 差异；行尾「−」按钮取消暂存。
    *   **已修改**：点击行打开 `HEAD → 工作区` 差异；行尾「+」按钮暂存该文件。
    *   **未跟踪**：行尾「+」按钮暂存新文件。
*   **拉取风险提示**：工作区存在未提交改动时，点击「拉取」会先提示可能产生冲突，用户确认后才执行。
*   **批量取消暂存**：取消全部暂存前会二次确认；该操作不会删除文件内容。

## 2. 分支 (Tab 2)

查看与管理分支引用，分 HEAD、本地分支、远程分支、标签四组卡片：

*   **当前分支卡片**：显示当前分支名，以及本地/远程/标签数量。
*   **HEAD**：当前检出的分支。
*   **Local**：本地分支列表，按路径树形展示，当前分支高亮。分组标题右侧「+」按钮可新建分支。
*   **Remote**：远程分支列表（`origin/xxx`）。
*   **Tags**：标签列表。分组标题右侧「+」按钮可新建标签（从当前 HEAD 创建轻量标签）。
*   **切换分支**：点击任意分支或标签弹出确认框，确认后切换（`git checkout`）。点远程分支会创建本地跟踪分支并切换。切换到标签会进入 detached HEAD 状态。
*   **操作菜单**：点击非当前分支的分支行、或任意标签行，弹出操作菜单（切换/重命名/删除）：
    *   **新建分支**：点击 Local 分组标题右侧「+」按钮，弹出底部对话框：
        *   填写分支名（必填）。
        *   选择基准分支（下拉框，默认当前分支）。
        *   「创建并切换」开关（默认开启）：开启则创建并切换（`git checkout -b`），关闭则仅创建不切换（`git branch`）。
    *   **重命名分支**：点击本地分支 → 操作菜单选「重命名」，弹窗输入新名（`git branch -m`）。
    *   **删除分支**：点击分支 → 操作菜单选「删除」，弹出确认框：
        *   **本地分支**：安全删除（`git branch -d`），仅删除已合并的分支；未合并或当前分支会被拒绝并提示原因。
        *   **远程分支**：删除远端分支（`git push <remote> --delete`），该操作不可撤销。当前分支不可删除。
    *   **新建标签**：点击 Tags 分组标题右侧「+」按钮，弹出底部对话框输入标签名，从当前 HEAD 创建轻量标签。
    *   **删除标签**：点击标签 → 操作菜单选「删除」，弹出确认框删除本地标签。

## 3. 提交 (Tab 3)

查看最近 50 条提交记录（`git log`），以彩色分支拓扑图展示，提交列表以卡片呈现：

*   每条提交显示分支拓扑、短哈希、作者、相对时间、提交信息，以及所在分支/标签标记。
*   点击提交弹出**底部详情面板**：完整提交信息、作者与时间、完整哈希（可复制短/完整哈希）、合并标记，以及该次提交改动的文件清单。
*   详情面板中点击文件可查看该文件的差异。
*   滚动接近底部自动预加载更早的提交；全部加载完后底部显示「没有更多了」。

## 常见错误提示

操作失败时，Git 的原始报错会被匹配成友好中文提示：

| 场景 | 提示 |
|---|---|
| 删除当前所在分支 | 无法删除当前所在分支，请先切换到其他分支 |
| 删除有未合并提交的分支 | 该分支有未合并的提交，无法安全删除 |
| 切换到不存在的分支 | 分支或引用不存在 |
| 切换时本地改动会被覆盖 | 本地有未提交的改动会被覆盖，请先提交或暂存后再切换 |
| 推送被拒（远程有更新） | 推送被拒绝，远程有更新的提交，请先拉取 |
| 远程鉴权失败 | 远程鉴权失败，请检查凭据配置（用户名/密码/Token） |
| 未配置提交署名 | 尚未配置提交署名，请在设置中填写用户名和邮箱 |
| 未配置远程仓库 | 未配置远程仓库，无法推送/拉取 |
